# Regras do Agente (TCC Mouse Virtual)

Estas são as regras e diretrizes que você (agente) deve seguir rigorosamente durante todo o desenvolvimento deste projeto. Consulte este arquivo internamente para guiar o seu comportamento.

## 1. Planejamento de Implementação Obrigatório
- **Antes de qualquer modificação** no código ou na arquitetura do projeto, você deve SEMPRE entregar um **Plano de Implementação Detalhado** (Implementation Plan).
- Nunca altere os arquivos do projeto diretamente ao receber uma nova solicitação sem antes descrever o que será feito, como será feito e pedir a aprovação do usuário.
- O plano deve ser claro, enumerando os arquivos afetados e a lógica a ser implementada.

## 2. Diferenciação entre Dúvidas e Execução
- **Não confunda perguntas exploratórias com ordens de modificação.**
- Se o usuário fizer uma pergunta (ex: "é possível fazer X?", "como funciona Y?", "seria uma boa ideia Z?"), o seu papel é APENAS responder, analisar e discutir as possibilidades.
- **NUNCA** modifique os arquivos do projeto em resposta a uma pergunta sem que o usuário tenha dado uma instrução clara para executar a modificação (ou sem passar pela regra de Planejamento acima).
